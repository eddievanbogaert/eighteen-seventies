# /primary

**Transcribed primary text only.** Nothing else goes in this directory: no
commentary, no paraphrase, no summary, no analysis. Those go in `/notes`.

The reason this directory exists is rule 5 in `AGENTS.md`. A paraphrase written
from memory drifts, and the drift is invisible — it reads as confidently as the
original. A transcription can be checked against the source character by
character. So the working order is always: transcribe first, then write about
the transcription, never write about the memory.

## What goes in a file here

Each file is one document or one passage, with its provenance recorded at the
top and the text below, unaltered. Provenance means enough that a reader could
find the same passage in the same edition: what the document is, who produced
it, the edition or printing transcribed from, where that copy came from, who
transcribed it and when.

If a detail of the provenance is unknown, write that it is unknown. Do not
estimate it, and do not leave it out — a transcription with silent gaps in its
provenance is not usable as evidence.

## Rules for the text itself

- Transcribe exactly, including spelling, capitalisation, and punctuation as
  they appear. Period spelling is not an error to be corrected.
- Mark every omission and every insertion visibly, so a later reader can see
  where the transcription departs from the page.
- Never repair a passage that seems garbled. If it is garbled on the page, it
  is garbled in the transcription, with a note in `/notes` saying so.
- Translations are not primary text. A translated passage is a transcription of
  a translation, and the translator is part of the provenance.
- Text that reaches us through an interpreter, a stenographer, or a
  journalist's reconstruction is a record of a transmission, not a record of
  what was said. Say so in the provenance. Chapter 18's surrender speech is
  the book's hardest case of this.
